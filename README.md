# NOIR — Премиальный барбершоп (Atelier)

Премиальный одностраничный веб-проект камерного барбершопа **NOIR** (Москва, ул. Тверская, 18).

Проект разработан по канонам современного редакционного дизайна: глубокая графитовая палитра, строгая европейская типографика (*Cormorant Garamond* + *Manrope*), выверенные асимметричные журнальные развороты, деликатный бордовый акцент и плавная кинематографичная анимация.

## 2. Локальный запуск

Сайт работает автономно без сборщиков и зависимостей Node.js.

### Вариант А: VS Code Live Server (Рекомендуется)
1. Откройте папку `NOIR/` в Visual Studio Code.
2. Установите расширение **Live Server**.
3. Нажмите правой кнопкой мыши на `index.html` → **Open with Live Server** (или `Alt+L Alt+O`).

### Вариант Б: Python встроенный HTTP-сервер
Откройте терминал в папке `NOIR/` и выполните:
```bash
python3 -m http.server 8000
```
Затем откройте в браузере: `http://localhost:8000`.

### Вариант В: Простое открытие файла
Дважды кликните по `index.html` в проводнике Windows / macOS. Все пути в проекте относительные (`./css/`, `./assets/`), поэтому страницы отобразятся корректно.

## 3. Публикация на GitHub Pages

1. Инициализируйте репозиторий Git и закоммитьте файлы:
   ```bash
   git init
   git add .
   git commit -m "Initial release of NOIR Barber Atelier"
   ```
2. Создайте публичный или приватный репозиторий на GitHub и отправьте код:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/noir-barber.git
   git branch -M main
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в **Settings → Pages**.
4. В разделе **Build and deployment → Branch** выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Наличие файла `.nojekyll` в корне гарантирует, что GitHub Pages не будет фильтровать системные файлы и папки. Через 1–2 минуты сайт станет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/noir-barber/`.

## 5. Демонстрационные данные и функционал

* **Контактные данные:** все номера телефонов (`+7 (999) 123-45-67`), адрес (`Москва, ул. Тверская, 18`) и ссылка на Telegram (`@noir_barber_demo`) носят демонстрационный характер концепт-проекта.
* **Что работает автономно на клиенте:**
  * Плавная прокрутка к разделам с учётом фиксированной шапки.
  * Автоматический трекинг активных разделов в навигации (ScrollSpy на IntersectionObserver).
  * Полноэкранный мобильный drawer с клавиатурной доступностью (Escape, Enter).
  * Маска ввода российского номера телефона `+7 (___) ___-__-__`.
  * Валидация всех обязательных полей с подсветкой ошибок и доступностью для скринридеров (`aria-invalid`, `aria-describedby`, `role="alert"`).
  * Динамическая блокировка прошедших дат (`min="YYYY-MM-DD"`).
  * Выбор временных слотов через интерактивные радио-чипы.
  * Живое резюме визита в боковой карточке (обновление услуги, стоимости, мастера, даты и времени).
  * Автоматический предвыбор мастера при клике на «Записаться» в секции Masters.
  * Модальное окно демонстрационной политики конфиденциальности.
  * Состояние подготовленной демонстрационной заявки с возможностью возврата к редактированию.
* **Что потребуется для подключения production-сервера:**
  * Замена обработчика `submit` в `js/main.js` (`NOIR.Booking.bindFormSubmission`) на вызов API CRM-системы (например, YCLIENTS, Altegio) или отправку `fetch('/api/booking', { method: 'POST', body: ... })` на собственный backend.
